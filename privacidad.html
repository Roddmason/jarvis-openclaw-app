Política de privacidad

Vigente desde el 26 de septiembre de 2026. Aplica a la aplicación «Jarvis (OpenClaw personal)».

Quién la usa

Una sola persona, su dueño, que la autoriza con su propia cuenta de Google. No hay otros usuarios.

Qué datos de Google usa y para qué

  • Contactos (solo lectura): resolver el nombre de un destinatario cuando el dueño pide enviar un mensaje.
  • Calendario: leer eventos para avisar de reuniones y crear o modificar eventos solo cuando el dueño lo pide.
  • Drive (solo archivos creados por la aplicación): subir los respaldos que el dueño pide. La aplicación no puede ver ni modificar el resto de sus archivos de Drive.

Dónde se guardan

Los tokens de acceso se guardan en el almacén de credenciales del sistema operativo del computador del dueño. La aplicación no mantiene una base de datos propia con esta información.

Con quién se comparten

No se venden ni se comparten con terceros. Para responder una solicitud del dueño, el fragmento necesario puede procesarse con el proveedor de modelos de IA que él mismo configuró; no se usa para publicidad ni para entrenar modelos por parte de esta aplicación.

El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

En myaccount.google.com/permissions, quitando el acceso a «Jarvis (OpenClaw personal)».
